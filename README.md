# Sky War

A dark Omarchy theme: near-black space, azure blue accent, and a painted starship hanging in front of a
moonlit planet. The wallpaper comes with a short animated intro that plays once and settles on the still.

## Install

```bash
omarchy theme install https://github.com/psychokk/omarchy-sky-war-theme
omarchy theme set sky-war
```

Intros play at boot, on theme switch and when picking the background.
Turn them off with `omarchy theme bg intro disable`.

## What's inside

- `colors.toml`: palette (drives terminal, Waybar, Walker, Mako, Hyprlock, SwayOSD, btop and more)
- `backgrounds/sky-war.jpg`: wallpaper (2576x1438)
- `backgrounds/intros/sky-war.mp4`: intro (6.5 s, 24 fps, H.264). The engines ignite, the stars twinkle,
  a glint sweeps across the hull and the camera eases back, ending exactly on the wallpaper
- `icons.theme`, `preview.png`
